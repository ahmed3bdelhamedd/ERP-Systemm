مشروع محاكاة نظام SAP ERP (SAP Fiori Dashboard)
نموذج واجهة مستخدم تفاعلي واحترافي مستوحى من نظام SAP Fiori / ERP العالمي، مصمم خصيصاً للغة العربية (RTL) مع دعم كامل للوضع الداكن (Dark Mode) وتجربة استخدام سلسة تحاكي الأنظمة المؤسسية الكبرى.

🚀 مميزات النظام الرئيسية
واجهة مستخدم عصرية (SAP Fiori Style): تصميم نظيف، بطاقات معلومات ذكية، وقوائم جانبية تفاعلية.

لوحة تحكم تفاعلية (Dashboard): عرض مؤشرات الأداء الرئيسية (KPIs) مثل المبيعات، الطلبات المعلقة، الإيرادات، ورضا العملاء.

إدارة المخزون (Inventory Management): جدول تفاعلي لإدارة المنتجات، الكميات، الحالات، ومستويات المخزون مع إمكانية إضافة منتجات جديدة.

إدارة الطلبات (Sales Orders): متابعة طلبات العملاء، حالات الطلب (مكتمل، قيد المعالجة، ملغي)، والقيم المالية.

محاكاة العمليات (Action Simulations): أزرار تفاعلية لإضافة بيانات حقيقية وتحديث لوحة التحكم فورياً.

دعم كامل للغة العربية: تخطيط من اليمين ليسار (RTL) مع مصطلحات محاسبية وإدارية دقيقة.

تصميم متجاوب (Responsive): يعمل بكفاءة عالية على الشاشات الكبيرة، الأجهزة اللوحية، والهواتف الذكية.

🛠️ التقنيات المستخدمة
HTML5 / CSS3: الهيكلة والتصميم الأساسي مع استخدام المتغيرات (CSS Variables) للتحكم بالألوان.

Tailwind CSS: إطار عمل لتنسيق الواجهات بسرعة ودقة عالية.

Alpine.js: لإدارة الحالة التفاعلية بسلاسة (مثل التبديل بين الأقسام، النوافذ المنخفضة، وإضافة البيانات).

Lucide Icons: حزمة أيقونات عصرية وواضحة.

Google Fonts (Cairo): خط عربي احترافي ومناسب لأنظمة الشركات.

⚙️ كيفية التشغيل
المشروع مصمم ليعمل كملف واحد (Single-File Component) لسهولة التجربة والاستخدام الفوري:

قم بتحميل الملف الخاص بالمشروع (sap_erp_simulation.html).

افتح الملف باستخدام أي متصفح إنترنت حديث (مثل Google Chrome, Microsoft Edge, أو Firefox).

استمتع بتجربة لوحة التحكم والتنقل بين الأقسام المختلفة.

📱 الأقسام المتاحة في النظام
لوحة التحكم (Dashboard): نظرة عامة على الإحصائيات والرسوم البيانية المصغرة والنشاط الأخير.

المخزون (Inventory): عرض حالة المنتجات وتتبع الأصناف المتاحة والمنخفضة.

المبيعات (Sales): متابعة طلبات العملاء والفواتير الحالية.

التقارير (Reports): استعراض التحليلات المالية والإدارية (قريباً / قابل للتوسع).

🤝 المساهمة والتطوير
إذا كنت ترغب في تطوير النظام أو ربطه بقاعدة بيانات حقيقية (مثل Node.js أو Python Backend مع SAP RFC/OData APIs)، يمكنك بسهولة تعديل ملف HTML واستبدال البيانات الوهمية (Mock Data) بنداءات API حقيقية.
